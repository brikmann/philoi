# Rank-up copy — composed headline (personal + social)

Each rank-up headline is **composed of two parts**, formatted:

> **`{personal}, {name}. {social}`**   →   e.g. *"In motion, Noah. Word is spreading."*

- **Personal** = a name-ready **stem** (no name stored); the algorithm appends `, {name}.`
- **Social** = a **standalone sentence, NO name.**
- Pick one personal + one social per rank-up, each with **no immediate repeat** (separate recent-history per user).
- Bronze personal lines are per-division (III / II / I); other tiers are tier-level. Social lines are tier-level.
- `{name}` = first name. `{school}` / `{mascot}` / `{rival}` = campus placeholders (fallbacks: "your school" / "your squad" / "the other schools"; beta = Laurier / Golden Hawks / Waterloo).
