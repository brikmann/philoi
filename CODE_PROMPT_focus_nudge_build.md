## What to build

### 1 · Config plugin (Expo prebuild has no notion of app extensions)
Mirror the existing **Widget/Live Activity extension plugin already in `app.config.ts`** (~line 269). Generate the three extension targets, each with: the Family Controls + App Groups entitlements, an Info.plist, and the `NSExtensionPointIdentifier` for its kind (DeviceActivityMonitor / ShieldConfigurationExtension / ShieldActionExtension). Add `mediaPlayback`-style capability wiring per extension type.

### 2 · The three Swift extensions
- **DeviceActivityMonitor** — on `intervalDidStart` / `eventDidReachThreshold`, apply `ManagedSettingsStore().shield.applications` to the user's selected app tokens.
- **ShieldConfiguration** — read the **pre-fetched nudge copy from the App Group** (shared `UserDefaults(suiteName:)` / file), render Cindy's nudge (title, body, primary + secondary button). Extensions can't reliably network — never fetch here; only read what the app already wrote.
- **ShieldAction** — handle taps: **primary = open Philoi to start a lock-in** (deep link), **secondary = defer / close** (per spec). Wire the §C-safety escape too — the "talk to someone" support surface already exists in-app.

### 3 · RN/JS side (main app)
- **Authorization:** `AuthorizationCenter.requestAuthorization(.individual)` — request on opt-in, handle denial gracefully.
- **App picker:** a `FamilyActivityPicker` surface so the user chooses which apps to guard; persist the selection (opaque tokens — never resolvable to app identities, by Apple's design).
- **Nudge-text handoff:** the app writes Cindy's current nudge copy into the App Group so the shield can read it offline. Refresh it on a schedule / on relevant events.
- **Start/stop monitoring** from a settings toggle; respect an off state.

## Guardrails
- **Own native build**, development-signed, on-device — smoke it there (Expo Go can't run extensions).
- **No networking in any extension** — the App Group is the only channel.
- App tokens are opaque; store/compare them, never try to resolve app names.
- Additive to `app.config.ts` — don't disturb the existing Widget/Live Activity extension config.
- Distribution entitlement is believed team-covered; if a TestFlight upload later bounces an extension on entitlement, file the per-bundle request then.
